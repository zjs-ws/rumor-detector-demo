# 指标六：端到端决断延迟 (End-to-End Time-to-Verdict)

## 一、背景与降维打击点

端到端决断延迟衡量的是：从用户在网页端点击"检测"，到 Agent 完成 **意图识别 → 关键词提取 → 调用搜索引擎 → 综合研判 → 渲染雷达图** 的全链路总耗时。

- **传统方法的痛点**：爬虫/图网络模型不仅需要等数据发酵（数小时甚至数天），即便跑起来，全网拓扑图的构建和渲染也极其耗时。而人工核查一条复杂谣言平均需要 **30 分钟以上**。
- **Agent 的降维打击**：Agent 将一个原本需要人工核查半小时的复杂辟谣任务，压缩到 **秒级** 自动化响应。虽然 Agent 比裸 LLM 做了更多事（搜索查证 + 多维评估 + 可视化），但额外延迟换来的是准确率和可解释性的飞跃。

**核心指标**：
- 平均延迟、中位数 (P50)、P90/P95/P99 百分位
- SLA 达标率（N 秒内完成的比例）
- 相对人工核查的加速倍数

## 四、如何对接你的 Agent

`benchmark_latency.py` 通过 HTTP POST 调用 Agent 接口，测量的是**网络传输 + 服务端全链路处理**的端到端耗时：

```
POST http://127.0.0.1:8000/detect
Content-Type: application/json

{"text": "网传某市自来水中检测出大量氯化物超标..."}
```

这个耗时包含了 Agent 内部的全部工作：
1. 意图识别
2. 关键词提取
3. 外部搜索引擎查证
4. LLM 综合研判
5. 多维度打分
6. 响应序列化

如果你的接口地址不同，用 `--api` 参数指定：

```bash
python3 benchmark_latency.py --target agent --api http://192.168.1.100:8000/detect
```

## 五、报告解读

### 核心指标说明

| 指标 | 含义 | 看什么 |
|------|------|--------|
| 平均延迟 | 所有请求的平均耗时 | 整体性能 |
| P50 (中位数) | 50% 的请求在此时间内完成 | 典型用户体验 |
| P90 | 90% 的请求在此时间内完成 | 大部分用户体验 |
| P95/P99 | 长尾延迟 | 最差情况 |
| 吞吐率 (QPS) | 每秒处理请求数 | 系统容量 |
| SLA 达标率 | N 秒内完成的请求比例 | 服务质量承诺 |

### 对比维度

报告会从三个角度对比：

1. **Agent vs 人工核查**：Agent 秒级 vs 人工 30 分钟 = 数百到数千倍加速
2. **Agent vs 基线 LLM**：Agent 可能稍慢于裸 LLM，但做的事情不在同一量级（裸 LLM 只是猜测，Agent 是查证）
3. **分桶对比**：短文本通常更快，长文本可能需要更多搜索时间

### 如何解释"Agent 比裸 LLM 慢"

这是**完全正常且有利的**：
- 裸 LLM 只调用一次 API、不做任何外部查证，当然快
- Agent 在这几秒内完成了搜索引擎查证 + 多维度分析 + 雷达图生成
- 这点额外延迟换来的是准确率从 X% 到 Y% 的提升、以及可追溯的查证依据
- 类比：CT 扫描比目测慢，但诊断结果靠谱得多

## 六、常见问题

**Q: 预热 (warmup) 有什么用？**
首次请求往往包含冷启动开销（模型加载、连接建立等），预热确保正式测试数据不被首次延迟污染。建议 `--warmup 5`。

**Q: 为什么要多轮测试 (rounds)？**
网络波动、服务端负载变化都会影响单次测量。多轮取平均能得到更稳定的结果。建议 `--rounds 3`。

**Q: Agent 的延迟很高 (>10s) 怎么办？**
检查 Agent 内部是否有不必要的串行调用。常见优化：
- 搜索引擎查询并行化
- LLM 调用使用 streaming
- 减少不必要的中间步骤

**Q: 如何修改人工核查的参照基准？**
默认人工核查一条谣言需要 30 分钟。如果你的场景不同：

```bash
python3 compare_latency.py --human-minutes 20
```

## 七、答辩展示建议

1. **三栏对比图**：Agent (3s) vs 裸LLM (1s) vs 人工 (30min)，用对数坐标或打断坐标轴
2. **CDF 曲线**：横轴延迟、纵轴累计完成比例，展示 Agent 的 P90/P95 拐点
3. **分桶柱状图**：短/中/长文本的延迟对比，说明 Agent 在各复杂度下都能秒级响应
4. **一句话总结**："Agent 将人工核查 30 分钟的工作压缩到 N 秒，加速 M 倍，且完成了完整的外部查证和多维评估"
