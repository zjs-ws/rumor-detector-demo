# 依据溯源率 (Faithfulness) 评测完整指南

## 一、这个指标在证明什么

大模型最大的隐患是**幻觉 (Hallucination)**——一本正经地编造不存在的"证据"来辟谣。

本指标量化的是：**当 Agent 判定某条内容为谣言时，它给出的辟谣依据是否真实可查、与结论一致。**

这直接回应评委最常问的灵魂拷问："你们的 Agent 辟谣时说的那些'据官方通报'，是真的有出处，还是它自己编的？"

---

## 二、核心定义

一条谣言判定算作**溯源成功**，必须**同时满足**两个条件：

| 条件 | 说明 | 反例 |
|------|------|------|
| **有明确外部线索** | 报告中包含可验证来源（官网链接、具体通报年份、权威媒体引用等） | 仅靠"一般来说""常识判断"做结论 |
| **线索与结论不冲突** | 引用的来源内容确实支持 Agent 的辟谣结论 | 引用的新闻实际上在支持原帖观点，Agent 却说是谣言 |

**核心公式**：

```
依据溯源率 = 溯源成功数 / 已标注总数
```

## 四、完整操作流程

### Step 1：提取候选案例

**前提**：已跑完指标一的 Agent 评测，生成了 `早期预警准确率/Agent评测/早期预警逐条结果.json`。

```bash
cd /Users/wangsheng/Desktop/数据集/依据溯源率

# 自动从指标一的 Agent 结果中提取
python3 extract_sourced_cases.py

# 如果 Agent 结果在其他位置
python3 extract_sourced_cases.py --input /path/to/你的Agent结果.json

# 最多抽取 100 条（默认）
python3 extract_sourced_cases.py --sample 100
```

脚本会：
- 筛选出 Agent 判定为**谣言**的案例
- 自动检测 reason 字段中是否包含外部证据线索（URL、年份、官方来源等）
- 输出 `溯源候选集.json` 供下一步人工标注

---

### Step 2：人工标注

提供两种标注方式，任选其一：

#### 方式 A：终端交互式标注（推荐个人使用）

```bash
python3 faithfulness_annotation.py
```

逐条展示案例，你只需输入 1/2/3/4 做判定：

```
──────────────────────────────────────────────────
  [1/80]
──────────────────────────────────────────────────
  原帖文本:
    震惊！某大学食堂用地沟油被曝光...

  Agent 辟谣理由:
    经检索，该校后勤处于2024年3月发布声明澄清，
    食堂用油均通过正规渠道采购并有检测报告...

  自动检测到的线索片段:
    • 2024年3月
    • 声明澄清
──────────────────────────────────────────────────
  标注 [1=溯源成功 2=有线索但冲突 3=无实质线索 4=幻觉] (s=跳过 q=保存退出):
```

- 输入 `q` 可中途保存退出，下次用 `--resume` 继续：

```bash
python3 faithfulness_annotation.py --resume
```

#### 方式 B：导出 CSV 多人协作标注

```bash
# 导出 CSV 模板
python3 faithfulness_annotation.py --export-csv

# 用 Excel/WPS 打开 溯源标注模板.csv，在"标注结果"列填写 1/2/3/4

# 标注完成后导入
python3 faithfulness_annotation.py --import-csv 溯源标注模板.csv
```

适合多人分工：把 CSV 拆成几份，各自标注后合并导入。

#### 标注选项说明

| 输入 | 标签 | 含义 |
|------|------|------|
| 1 | 溯源成功 | 有明确外部线索，且与结论一致 |
| 2 | 有线索但冲突 | 引用了来源，但内容与结论矛盾 |
| 3 | 无实质线索 | 没有任何可验证的外部来源，纯靠推理 |
| 4 | 幻觉/捏造 | 引用了不存在的来源或编造了事实 |

## 六、常见问题

### Q1: 候选集为空

**原因**：Agent 评测结果中没有 `predicted_label == "rumor"` 的记录，或文件路径不对。

**解决**：确认指标一的 Agent 评测已跑完，且 `--input` 路径正确。

### Q2: 标注到一半想退出

输入 `q` 保存退出，下次运行时加 `--resume`：

```bash
python3 faithfulness_annotation.py --resume
```

### Q3: 想让多人同时标注

```bash
# 导出 CSV
python3 faithfulness_annotation.py --export-csv

# 把 CSV 拆成多份分给不同人
# 标注完合并后导入
python3 faithfulness_annotation.py --import-csv 合并后的.csv
```

### Q4: Agent 的 reason 字段为空

说明你们的 Agent 接口没有返回推理理由。需要在 Agent 端确保返回 `reason` 或 `explanation` 字段。没有理由文本的情况下，所有案例都会被标为"无实质线索"，溯源率会很低。
