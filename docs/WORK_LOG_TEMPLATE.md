# 小组工作日志模板与里程碑骨架

> 工作日志计入课程总评 10%，按"实际投入时间"如实记录。以下模板字段与课程
> 要求一致；里程碑骨架按 git 历史整理，两位成员可逐条补充实际投入时间，
> 最终投入时间汇总用于核算贡献比（目标约 6:4，见
> [docs/TEAM_CONTRIBUTIONS.md](TEAM_CONTRIBUTIONS.md)）。

## 日志模板（每日）

```text
日期：
成员：
计划任务：
实际投入时间：
完成结果：
相关 Issue/Commit：
测试或截图：
遇到的问题：
解决方案：
下一步：
```

## 每周汇总模板

```text
第 X 周（日期范围）：
本周完成项：
延期项：
风险：
下周目标：
投入时间小计：A 共 X 小时 / B 共 X 小时
```
