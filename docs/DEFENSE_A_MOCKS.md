# RumorBuster 线上问答练习

这份练习不要求主讲项目。目标是听到老师的问题后，在 10 秒内找到资料，并用通俗语言回答。

## 第一轮：查资料回答，45 分钟

1. 一人随机读下面的问题；
2. 回答人可以打开 [线上答辩问答资料](DEFENSE_A_STUDY_PACK.md)；
3. 10 秒内找到对应章节；
4. 先用 20—40 秒回答；
5. 提问人再追问一次“为什么”或“代码在哪里”；
6. 记录找不到、答太长或说错的题。

### 问题池

1. 你们的项目到底解决什么问题？
2. 为什么不直接问大模型？
3. Agent、LangGraph 和 DeerFlow 分别是什么？
4. 你们复用了什么，又自己做了什么？
5. 用户输入一句话后，系统按什么顺序运行？
6. V3 为什么比 V2 更容易控制？
7. 怎样证明几个任务确实同时运行？
8. 搜索任务失败以后怎么办？
9. 什么样的网页可以用于最终判断？
10. 为什么官方网站不一定是 A 类？
11. 为什么要一条 A 或两条 B？
12. 两家网站转载同一篇稿件，算两个来源吗？
13. 怎样防止模型编链接和编原文？
14. RAG 为什么不能直接决定真假？
15. LoRA 在系统中到底有什么作用？
16. 微调后的 3B 模型测了多少条，结果是多少？
17. 时间记录为什么不能叫绝对源头？
18. 40 条、127 项和 178 项各代表什么？
19. 你和队友分别做了什么？
20. 当前项目最大的不足是什么？

## 第二轮：老师连续追问，35 分钟

这轮仍可看资料，但不能整段照读。每个回答必须先说结论。

### 连续追问题

1. 这是不是 DeerFlow 套壳？请给具体代码证明。
2. 既然最后由规则计算，为什么还需要大模型？
3. A/B 标准是谁规定的，有没有绝对正确？
4. 如果官方机构自己的内容有错误怎么办？
5. 没搜到反对材料，为什么不直接判为真实？
6. 实时搜索经常变化，这个系统还有什么价值？
7. 离线指标是 1.0，是不是针对测试写规则？
8. 为什么最新测试还有两项失败？
9. 3B 模型准确率已经有 90%，为什么还不能让它直接决定真假？
10. RAG 不参与最终判断，有什么实际作用？
11. 用户在同一聊天中问第二个问题，会不会误用第一次的证据？
12. 如果大模型最后写了和规则相反的结论怎么办？
13. 为什么不换一个更强的大模型解决所有问题？
14. 贡献比例为什么是 6:4？
15. 再给一周，你最先做什么？

## 答题检查表

| 检查项 | 达标标准 |
|---|---|
| 找资料速度 | 10 秒内找到对应问题 |
| 先答结论 | 第一两句话直接回答问题 |
| 语言通俗 | 不连续堆叠三个以上英文或框架术语 |
| 答案长度 | 第一轮回答不超过 40 秒 |
| 追问处理 | 能补充原因或指出代码位置 |
| 数据准确 | 1940/90%、40、127、178/2 的含义不混淆 |
| 不夸大 | 不把模型离线准确率说成系统联网准确率 |
| 分工准确 | 训练与接入、后端与前端归属不混淆 |
