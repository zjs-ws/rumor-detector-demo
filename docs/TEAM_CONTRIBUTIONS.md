# 成员分工与贡献（提交版）

## 总体分工

项目在 DeerFlow 开源框架基础上完成 RumorBuster 谣言核验系统的领域化开发。
成员一（zjswz111）负责智能体与后端核心工作流及 LoRA 微调模型训练；成员二
（baitea）负责微调模型系统接入与调试、子智能体执行稳定化、证据-前端衔接
以及评测与答辩材料。两人共同完成需求分析、演示案例、报告校对、模拟答辩
与视频录制。贡献比约 **6:4**，依据小组工作日志投入时间与 Commit、产物
记录核算。

## 成员一（zjswz111）：智能体与后端 + 微调训练

1. 谣言核验 V3 显式 LangGraph 状态图：可核验性分流、并行取证分支（本地
   RAG、普通网页研究、可选 LoRA 分类、专业权威研究、时间线研究）、
   reducer 汇合与确定性裁决；
2. 确定性证据规则：一条职权匹配 A / 两条独立 B 的裁决门槛、来源分级、
   独立性/直接性/时效性校验、证据排除原因链；
3. 受控权威来源注册表（22 条官方来源）与确定性研究计划：实体别名匹配、
   领域词修正、锁定官方域名查询；
4. 信息源改造：Tavily 搜索与结构化抓取协议、本地抓取加固（浏览器 UA、
   有限重试、重定向上限、PDF 正文提取）、DuckDuckGo 备选；
5. 汇合后确定性补抓与候选扫描：代码抓取网页、按主张关键词逐字选取引文，
   失败保持排除、不降低裁决门槛；
6. 统一核验 API（`POST/GET /api/v1/checks`）与制品下载安全策略；
7. 浏览器划词核验扩展（Chrome Manifest V3）；
8. 评测体系：40 条离线评测清单、30 条真实联网验收脚本、演示案例留痕脚本、
   模型微调 6 项基准评测脚本；
9. 基于 LLaMA-Factory 的 LoRA 微调模型训练与数据集处理；
10. 部署编排与文档：Docker Compose 生产编排、一键启动脚本、快速上手指南。

## 成员二（baitea）：模型接入调试 + 稳定化 + 评测材料

1. 微调模型系统接入与调试：ModelScope `/v1/chat` 与 OpenAI Chat 双协议
   适配、`Yes/No/Unknown` 标签精确映射、超时与非法标签安全降级、
   子主张级审计信息记录；
2. 子智能体工具执行故障诊断与稳定化：定位并修复工具执行与断点配置问题，
   保障受限研究员的稳定运行；
3. 证据-前端衔接：研究结果 `fetch_attempts` 字段归一化、前端消息按
   `tool_call_id` 乱序归组、结构化报告卡片与空值防护、工作区布局稳定性；
4. 本地构建稳定性：构建超时参数与前端动态加载优化；
5. 30 条真实联网验收执行与失败案例分析；
6. 三组对比评测（大模型直接判断 / 模型+检索 / 完整系统）执行与指标图表
   制作（准确率、引用可追溯率、虚构链接率、延迟等）；
7. 数据集来源说明撰写（训练集、原测试集与 Benchmark 的来源与冻结说明）；
8. 测试维护与 bug 修复、答辩材料整理与 PPT/演示脚本。
