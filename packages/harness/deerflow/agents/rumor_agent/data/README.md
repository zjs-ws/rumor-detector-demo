# 已核验谣言知识库

`verified_rumors.jsonl` 是课程版轻量 RAG 数据源，目前 30 条，均标记为 `review_status=reviewed`。每条包括规范主张、常见变体、历史结论、权威来源、人工说明、复核日期和可选时效提醒。

`source_registry.json` 是来源等级的可审计配置。它记录官方机构域名及其职权关键词、专业来源域名和个人来源特征；代码还会读取已复核知识库中的权威来源域名，但这些域名不会因此自动获得当前主张的 A 级职权匹配。

当前来源集合：

- WHO COVID-19 Mythbusters：历史疫情错误说法；
- FDA Health Fraud Scams：医疗欺诈常见承诺；
- NASA Climate Change Evidence：气候变化基础证据。

维护规则：

1. 只能加入人工打开并核对过的来源 URL；
2. `reviewed_at` 记录本项目最后复核日期，不冒充页面发布日期；
3. 涉及政策、药品、疫情等可能变化的内容必须写 `temporal_warning`；
4. 一个来源可拆为多条明确主张，但评测应说明来源多样性限制；
5. RAG 返回始终 `authoritative=false`，历史命中不得直接用于当前裁决；
6. 新增或修改记录后运行 `tests/test_rumor_rag.py` 和离线评测。
7. 新增官方来源时必须同时填写职权关键词；仅有政府域名格式而无职权匹配时最高按 B 级处理。

课程演示应主动说明：30 条是可解释的种子库，覆盖面有限；它证明的是“检索链路、变体召回和与实时证据分权”，不是宣称已经建成大规模事实库。
